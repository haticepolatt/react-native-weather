# React Native Hava Durumu Uygulaması

Bu proje, **React Native** ve **Expo** kullanılarak geliştirilmiştir.  
Kullanıcıdan şehir adı alır ve **OpenWeatherMap API** üzerinden anlık sıcaklık, durum ve ikon bilgilerini gösterir.

---

# Özellikler
- Şehir adıyla hava durumu sorgulama
- Gerçek zamanlı sıcaklık verisi
- Açıklama ve ikon desteği
- Minimalist arayüz (Antalya varsayılan şehir)

# Kurulum ve Çalıştırma
Projeyi klonla:
```bash
git clone https://github.com/haticepolatt/react-native-havadurumu.git
cd react-native-havadurumu
npm install
npm start
```
